# OTIUM — Coming Soon

The official **OTIUM coming-soon landing page**, where users can pre-register for early access.

## Overview

OTIUM is preparing for launch. This landing page introduces the brand and gives visitors the opportunity to join the early-access list.

## Features

- Coming-soon landing page
- OTIUM brand introduction
- Early-access pre-registration
- Email collection for launch updates
- Responsive design for desktop and mobile

## Tech Stack

- HTML
- CSS
- JavaScript

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project:

```bash
cd otium-coming-soon
```

Open the landing page in your browser or run it using your preferred local development server.
